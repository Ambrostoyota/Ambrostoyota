## How the register will be updated

For each new result, add: title, repo + immutable commit, run date, raw log location, exact command to reproduce, hardware/software environment, independent checker, limitations, and review status. For any sponsorship contribution, maintain financial records separately and disclose public totals only with permission and appropriate safeguards.

**Research integrity rule:** An honest empty result table is stronger than invented benchmark numbers.
