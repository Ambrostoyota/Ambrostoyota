# Ambro Zhong | Independent AI Research

**Open-weight models · Autonomous agents · Reproducible evaluation**

I'm an independent developer in Los Angeles County exploring how open-weight language models can support reliable, transparent AI research and software engineering.

My current research direction focuses on:
- **Autonomous agents:** planning, tool use, error detection, and controlled execution.
- **Multi-agent evaluation:** comparing specialist agent teams with single-agent baselines.
- **Local LLM systems:** memory requirements, inference performance, and resource-efficient experiments.
- **AI-assisted development:** reproducible tests for code generation, debugging, and automated experimentation.

### Research approach

1. Establish hardware and software baselines with published methodology.
2. Compare single-agent systems on defined coding and tool-use tasks.
3. Evaluate multi-agent setups under comparable workloads and budgets.
4. Test bounded automation workflows with independent validation and clear human oversight.
5. Publish reproducible results and research limitations.

This project is intended for **local inference, evaluation, agent orchestration, and suitably sized fine-tuning**—not training frontier-scale models from scratch.
